# 검증 체크리스트

요구사항 정의서의 검증 원칙에 따라 실행 결과와 화면 캡처를 증빙으로 남깁니다. 아래의 미체크 항목은 실제로 수행한 뒤 결과와 캡처 경로를 기록하세요. 문서 작성 시점에 정식 자동 테스트 파일은 확인되지 않았습니다.

## 코드·데이터 정적 확인

- [x] 앱 화면, 색인 코드, 환경변수 이름과 CSV 스키마를 확인했습니다.
- [x] CSV가 2,918행·9개 컬럼이며, 앱과 색인 코드의 전체 컬럼 `dropna()` 기준으로 501행이 남는 것을 확인했습니다.
- [x] 현재 코드에서 MMR과 RAG 전후 품질 비교 경로를 찾지 못했습니다.
- [ ] Kaggle 원본 URL, 작성자, 라이선스, 재배포 조건을 확인했습니다.

## 실행 검증

- [ ] 새 가상환경에서 `pip install -r requirements.txt`가 성공합니다.
- [ ] `.env`가 없거나 `GMS_KEY`가 비어 있을 때 키를 노출하지 않고 안내합니다.
- [ ] `python 1_index_meta.py` 실행 후 Chroma 컬렉션 문서 수가 예상치와 일치합니다.
- [ ] 색인 스크립트를 두 번 실행해도 중복 문서가 증가하지 않습니다. (현재 구현에서는 실패할 수 있습니다.)
- [ ] 운동 둘러보기에서 부위를 선택하고 운동 상세·난이도·기구·설명을 확인합니다.
- [ ] 조건 추천에서 부위·난이도·기구 조건에 맞는 결과만 표시되는지 확인합니다.
- [ ] 지식 질문의 답변에 표시된 근거 번호가 실제 출처 목록과 대응하는지 확인합니다.
- [ ] 위키 검색 결과 없음, 네트워크 오류, 색인 없음 상황에서 사용자가 이해할 수 있는 안내를 확인합니다.
- [ ] 반복 질문에서 위키 재수집·임베딩 동작과 응답 시간을 기록합니다.
- [ ] 대표 질문 5개 이상으로 RAG 미사용/사용 답변을 나란히 비교하고 사실성·근거 표시·모름 응답을 기록합니다. (F2015)
- [ ] API 키, 전체 프롬프트, 개인정보가 화면·로그·제출 캡처에 노출되지 않는지 확인합니다.
- [ ] 루틴 추천 결과에 검색 근거가 없다는 범위와 건강 안전 안내를 확인합니다.

## 우선순위 높은 미통과 위험

- 전체 컬럼 결측 제거로 운동 데이터의 17%만 색인·탐색 가능합니다 (501 / 2,918행).
- 색인 스크립트 재실행 시 중복 색인이 생길 수 있습니다.
- 외부 HTTP 호출에 timeout이 없어 응답 지연 요구사항을 보장하지 않습니다.
- MMR 및 RAG 전후 비교 요구사항은 현재 구현에서 확인되지 않았습니다.
